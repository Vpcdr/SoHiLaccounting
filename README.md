# حسابانه
نرم‌افزار حسابداری جمع‌وجور فارسی (تک‌فایل HTML، بدون نیاز به سرور).

## اجرا
- فایل `index.html` را در مرورگر باز کنید (دوبار کلیک).
- داده‌ها در localStorage مرورگر ذخیره می‌شوند؛ از تنظیمات > پشتیبان‌گیری استفاده کنید.

## انتشار روی GitHub Pages
1. مخزن جدید بسازید و `index.html` را آپلود کنید.
2. Settings > Pages > Branch: main / root > Save.
3. آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.
